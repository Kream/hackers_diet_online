## Operational memory (do not ignore)
# - After any rsync of the snapshot, the tree is writable by root. Immediately:
#     sudo chown -R www-data:www-data ~/dev-hackers-diet/hackdiet-data && sudo chmod -R u+rwX,g+rwX ~/dev-hackers-diet/hackdiet-data
#   or the CGI will fail to write .hdb files.
# - docker cp OUT of the container fails or is unreliable because of the read-only rootfs.
#   Always cat or curl the file content out:
#     docker exec dev-hackers-diet cat /tmp/foo.html > ~/local/foo.html
# - Session id is in the query string (s=...), never in the cookie jar.
# - Create the account and perform the first login under the frozen clock,
#   otherwise the month view stays pinned to the real wall-clock month.
# - The chart PNG is generated by the CGI; fetch it with curl under the same session
#   and save the bytes; do not rely on browser rendering.
